# Portal Ejecutivo de Licitaciones y Homologación de Proveedores
### Next Level S.A.S. — Sistema Autónomo de Monitoreo y Estructuración de Ofertas

Plataforma ejecutiva interactiva desplegada en GitHub Pages para la visualización en tiempo real de:
- Cartera de propuestas radicadas y en estructuración (CCB, Grupo Bicentenario, BogotáBio, MinTIC, EPC).
- Radar de oportunidades SECOP II y contratos corporativos de la Región Caribe / Mamonal.
- Directorio de homologación de proveedores para grandes compradores.
